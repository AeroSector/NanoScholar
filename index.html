    Backend Integration Architecture (Java / Spring Boot Ready)

    This frontend is intentionally designed as pure semantic HTML5 and vanilla CSS to allow seamless templating by the Java backend team:

    • Thymeleaf / JSP Templating: All DOM components use standard semantic tags (<article>, <section>, <dl>) with standard attributes ready for th:each, th:text, or JSTL expressions.
    • RESTful API Endpoints: Data structures in /src/data.ts map 1-to-1 to standard Java DTO models: LessonDTO, QuizQuestionDTO, and SubjectDTO.
    • Stateless Client Execution: Quizzes and offline storage operate client-side to minimize expensive server roundtrips, reducing Java server CPU and network traffic.
